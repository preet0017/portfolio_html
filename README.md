# 💼 Preet Bansal - Portfolio

A modern, fully responsive personal portfolio website built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. This portfolio showcases my skills, projects, experience, and contact information with a clean and developer-focused UI.

🌐 **Live Demo:** https://preet0017.github.io/portfolio_html/

---

## 🚀 Features

- 🎨 Modern dark-themed UI
- 📱 Fully responsive design
- ⚡ Smooth scrolling navigation
- ⌨️ Animated typing effect
- 🎭 Scroll reveal animations
- 📂 Project showcase section
- 💼 Experience & Education timeline
- 📧 Contact form
- 📍 About section with profile
- 🌙 Clean and minimal design
- 🚀 Fast loading (Pure HTML, CSS & JavaScript)

## 🖥️ Getting Started

Clone the repository


```bash

```

Simply open `index.html` in your browser.

Or use VS Code Live Server.
